# Legacy bridge source

This directory contains the original WPF prototype and is retained only for historical comparison. It is not the supported bridge and is not used by the root build, publish, or installer scripts.

Use Moment, the native WinUI 3 implementation in [`../quick-capture-bridge-winui`](../quick-capture-bridge-winui/). Its traditional EXE installer, configurable global shortcuts, WinUI PiP panels, vault routing, and startup registration are documented there.
