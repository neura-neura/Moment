# Moment

<img src="quick-capture-bridge-winui/Assets/MomentIcon.png" alt="Moment icon" width="180">

Moment is a native Windows capture application designed for nearly frictionless thought capture, with two optional Obsidian plugins for users who want in-Obsidian commands:

- **Quick Daily Capture** - hotkey, type, Enter. The text is inserted into today's Daily Note using the timestamp from the instant the command was invoked.
- **Quick Voice Notes** - hotkey, speak, hotkey. The audio is saved immediately and can then be transcribed locally with the official Whisper model family through `whisper.cpp`.
- **Moment** - native WinUI 3 Windows application with configurable global shortcuts (including F13-F24), compact PiP text/voice capture, Daily Note routing, WebM storage, and optional local Whisper transcription while Obsidian is closed.

Moment operates independently. Configure its text-note and voice settings directly in the native UI; the plugins remain optional for users who want in-Obsidian commands. Moment reads Obsidian's Daily Notes/Periodic Notes configuration directly and preserves insertion, heading, timestamp, audio embed, transcription destination, and Whisper model choices.

## Development

Requirements: Node.js 20 or newer and npm.

```powershell
npm install
npm run verify
npm run package
```

`npm run verify` runs strict TypeScript checks, ESLint, automated tests, production builds for both plugins, and a Release build of the native WinUI 3 Moment application.

## Installable packages

After `npm run package`:

- `quick-daily-capture/dist/quick-daily-capture.zip`
- `quick-voice-notes/dist/quick-voice-notes.zip`

Each archive contains a correctly named plugin directory with `main.js`, `manifest.json`, and `styles.css`.

The Moment installer is generated by `npm run package:bridge` in `quick-capture-bridge-winui/dist/` as a real NSIS x64 EXE installer; packaging leaves only that installer in `dist`. The current public installer is available from [release v1.2.0](https://github.com/neura-neura/Moment/releases/tag/v1.2.0).

See each plugin README for legacy in-Obsidian commands, [INTEGRATION.md](INTEGRATION.md) for the compatibility API, [RESEARCH.md](RESEARCH.md) for architecture decisions, and [MANUAL-TEST-PLAN.md](MANUAL-TEST-PLAN.md) for in-app verification.

See [quick-capture-bridge-winui/README.md](quick-capture-bridge-winui/README.md) for migration, independent processing, and real NSIS EXE installer instructions.

Moment is designed to work alongside Obsidian, but its global text capture, WebM recording, Daily-file routing, and local Whisper processing can also run while Obsidian is closed or without the capture plugins. Source and releases are published at [github.com/neura-neura/Moment](https://github.com/neura-neura/Moment), with the current installer at [release v1.2.0](https://github.com/neura-neura/Moment/releases/tag/v1.2.0).
